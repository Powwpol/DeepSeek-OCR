    {

        "deepseek-ocr": {
          "command": "python3",
          "args": ["/absolute/path/to/deepseek_ocr_mcp_server.py"],

            "DEEPSEEK_OCR_MODEL_PATH": "deepseek-ai/DeepSeek-OCR"

💡 TIPS

  • Use absolute paths in config files
  • Test with small images first
  • Enable crop_mode for large images (>640x640)
  • Use document_markdown template for best results
  • Pre-download model to avoid delays
  • Monitor GPU memory with nvidia-smi

🆘 TROUBLESHOOTING

  Issue: Packages not found
    → pip install -r mcp_requirements.txt --force-reinstall

  Issue: CUDA out of memory
    → Reduce DEFAULT_GPU_MEMORY_UTILIZATION in server.py
    → Reduce MAX_CROPS in config.py

  Issue: Model not found
    → huggingface-cli download deepseek-ai/DeepSeek-OCR
    → Check DEEPSEEK_OCR_MODEL_PATH

  Issue: Slow performance
    → Ensure GPU is used (check nvidia-smi)
    → Use crop_mode=False for small images
